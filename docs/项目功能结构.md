## 一、项目定位

一个跑在本机的 **Warframe 桌面悬浮助手**：Electron 透明悬浮窗 + 本地 Express 服务 + 大模型 Agent + 两个 MCP 数据服务（26 个工具）。

只做只读查询与文本建议：不注入游戏、不自动化操作、不上传库存；数据口径统一为**国际服 PC**，断源只标注不估算。

## 二、功能结构

```
Warframe 本地助手（Ordis 全息悬浮窗）
├─ 交互层 · Electron 悬浮窗
│  ├─ 收起态：90px 全息晶体（13 帧动图 WebP / 浮动·呼吸 / 无边框 / 无任何底色）
│  ├─ 展开：单击图标 0.22s 缩放淡入；鼠标离开 1 秒自动收起
│  ├─ 遗物模式：🎁 高亮后锁定不收起，粘贴奖励图自动识别
│  ├─ 窗口操作：拖图标或标题栏移动 / 面板把手缩放（≥300×240）/ 图标等比 80–150（记忆尺寸）
│  ├─ 左右自适应：图标在右半屏面板向左开，在左半屏向右开且图标镜像
│  ├─ 输入：文本 / Ctrl+V 截图（压缩+预览+可取消）/ 发送 / Ctrl+Shift+Q 退出
│  ├─ 菜单：☰ 二级菜单（遗物速查数据更新 / API 凭据 / 退出），子项切到面板内视图
│  └─ 渲染：Markdown（表格 / ◆ 列表）/ 代码块一键复制密语 / 图片气泡可放大
├─ 服务层 · Express（127.0.0.1:3000）
│  ├─ /api/chat 流式 SSE（打字机效果，失败回退非流式）
│  ├─ /api/settings GET/POST 三项凭据，保存后热重连库存服务
│  ├─ /api/relic-pick 开核桃秒选（截图 → 本地查表 → 推荐）
│  ├─ /api/relic/status · /api/update-relics · /api/update-prices（后台任务 + 409 防重）
│  ├─ /api/history/clear 清空上下文
│  ├─ /api/mcp 自检（工具数 / 凭据 / wiki / MCP 路径）
│  └─ 安全红线：RMT 关键词服务端硬拦截（2ms 返回，不调模型）
├─ Agent 层 · Ordis
│  ├─ 人设：Cephalon Ordis（Operator 称呼 / 故障口癖 / 立刻道歉）
│  ├─ 强制工作流：问推荐/今天做什么 → 先查库存 + 世界状态；读不到只说明，不猜
│  ├─ 上下文：最近 8 轮；图片只保留最近 2 轮
│  ├─ 工具循环：最多 6 轮，按意图从 26 个工具里裁剪
│  ├─ 结果缓存：库存 45s / 精通 300s / 配卡 30s（只缓存成功结果）
│  └─ 流式输出：SSE 增量渲染
├─ 工具层 · MCP（26 个）
│  ├─ wf_market（自研，15 个）
│  │  ├─ 属性类：get_item / get_warframe / get_weapon / get_mod / compare_weapons / search_items
│  │  ├─ 价格类：check_market（最低价/在线中位/卖家/收购单/密语）
│  │  ├─ 掉落类：search_drops / farm_guide / recommend_build
│  │  ├─ 遗物类：relic_drops（遗物四档概率 / 按部件反查）
│  │  ├─ 世界状态：world_state（昼夜/裂缝/突击/虚空商人/入侵/警报）
│  │  ├─ wiki：search_wiki（灰机中文正文，隐藏窗口过 Cloudflare）
│  │  └─ 建议类：beginner_guide / daily_picks（结合库存时优先用库存数据）
│  ├─ wf_inv（AlecaFrame，11 个）
│  │  ├─ 库存：get_alecaframe_inventory / get_owned_inventory / get_mastery_fodder
│  │  ├─ 配卡：get_frame_build / analyze_build
│  │  ├─ 紫卡：get_riven_mods / get_riven_auctions
│  │  └─ 其它：get_syndicate_standings / get_focus_progress / can_craft / search_market_item
│  └─ 失败即标注：库存不可读 / 数据源不可达，不编造
├─ 数据源与管道
│  ├─ warframe.market v2：实时买卖单（物品清单 12h 缓存，启动预热）
│  ├─ DE worldState + tenno.tools：世界状态（60s 缓存 + 55s 预热 + 6h 快照兜底）
│  ├─ 灰机 wiki：中文词条正文（本地 3001 桥接：/search /page /raw /pages）
│  ├─ AlecaFrame：本机 lastData.dat（库存/紫卡/配卡/声望）
│  ├─ warframe-items：离线 1.5 万条装备 / Mod / 掉落
│  ├─ drop.wf.wiki：遗物奖励库（799 遗物 / 4795 奖励，四档概率）
│  └─ 遗物价目：部件表 612 条（中文 605）+ 价格表 597 条有价 + 中英对照 655 条
└─ 工程 · 运维 · 合规
   ├─ 启动器：start-overlay.vbs / .bat，单实例，自动拉起后端与两个 MCP
   ├─ 退出清理：taskkill /T 结束 server.js 与 MCP 子进程，不留孤儿
   ├─ 日志：debug.log（窗口/动画）· server.log（接口/工具）
   ├─ 文档：使用说明 / 项目说明书 / 功能结构 / tools 说明
   ├─ 合规：只读查询、不注入游戏、不做自动化、不批量抓取
   └─ 口径：全部国际服 PC，断源只标注不估算
```

## 三、两条核心链路

### 3.1 问答链路

```
点击图标 → 展开面板 → 输入/粘贴截图
      ↓  POST /api/chat（stream:true）
Express → 红线检查（RMT 命中直接返回固定警报）
      ↓
Agent（Ordis 提示词 + 8 轮上下文 + 按意图裁剪后的工具）
      ↓  tool_calls（可并行）
MCP：wf_market（market v2 / 世界状态 / wiki / 遗物 / 离线库）
     wf_inv（AlecaFrame 本地缓存）
      ↓  工具结果回填 → 模型续写（≤6 轮）
SSE 增量 → 前端边收边渲染 Markdown → 代码块一键复制
```

### 3.2 开核桃链路

```
点 🎁 进入遗物模式（面板锁定，不自动收起）
      ↓  Ctrl+V 粘贴奖励截图
POST /api/relic-pick
      ↓
OCR（deepseek-flash，原样输出屏幕中文，不翻译）
      ↓
本地翻译（relic_zh 中英对照 + 部件词表）→ 查 all_relics（612 条）
      ↓
查 relic_prices（597 条）→ 排序（Forma 规则 / 价格降序 / ±2p 比杜卡德）
      ↓
返回「推荐选 + 其余估值」（0.8 秒，匹配 1–3ms）
```

## 四、关键取舍

| 主题 | 结论 | 原因 |
|---|---|---|
| 悬浮窗材质 | 透明窗口 + 页面全透明，图标区禁止任何底色/边框/阴影 | 透明窗口里 `mix-blend-mode` 无法去底，黑底会露方框 |
| 展开动画 | 只用 0.92→1 的轻微缩放淡入 | 更小的起始值会在图标旁闪出小方块 |
| 拖动实现 | 页面 JS + `setPosition`，位置对齐 4px | CSS `-webkit-app-region: drag` 在透明窗口+动画下失灵；不对齐会因 125% DPI 每拖一次胖 2px |
| 世界状态 | DE 官方 + tenno.tools 双源并行，6h 快照兜底 | 单源不稳；快照必须标注时间，不能当实时 |
| wiki | 隐藏窗口过一次 Cloudflare 后本地桥接 | 直接 fetch 一律 403 |
| 遗物名称 | OCR 只认字、本地做翻译 | 让模型翻译会编出 `Kullervo`/`Dragon Nikana` 这类不存在的名字 |
| 遗物价目 | warframe-items + drop.wf.wiki + 灰机中文 + market 现价 | 四层来源互补，缺一层就有盲区 |
| 价格防钓鱼 | 最便宜 8 单取中位，剔除低于中位 30% 的单 | 恶意低价单会把均价带偏 |
| 杜卡德估算 | 按遗物基础概率分档（15/45/100），标注「约」 | 离线库缺该字段；回测准确率 89.9% |
| 安全 | RMT 关键词服务端硬拦截 | 提示词约束不可靠，代码层才是硬保证 |
| 不确定时 | 明确标注「库存不可读」「数据源不可达」 | 宁可少说，不可编造 |
