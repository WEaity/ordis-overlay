> 配套文档：[`项目说明书.md`](./项目说明书.md)（工程实现）、[`项目功能结构.md`](./项目功能结构.md)（功能树）

## 1. 项目定位

这是一个**跑在本机的 Warframe 桌面悬浮助手**，只为你一个人服务。

- 它在游戏画面上悬浮一个 90px 的全息晶体图标，点开是磨砂面板；
- 你可以用日常语言问装备、价格、掉落、世界状态、配卡；
- 可以按 `Ctrl+V` 把游戏截图直接粘进去，它会认图并给结论；
- 开核桃（遗物）时，截一张奖励图，0.8 秒告诉你拿哪个。

### 它做什么

| 做 | 不做 |
|---|---|
| 只读查询：属性 / 价格 / 掉落 / 世界状态 / 库存 | ❌ 不读游戏内存、不注入进程 |
| 生成可复制的交易密语文本 | ❌ 不代替你发消息、不自动交易 |
| 基于你本机库存给建议 | ❌ 不上传库存、不建账号体系 |
| 遗物奖励截图识别与推荐 | ❌ 不做账号交易 / 代练 / 代充 |

**一句话**：一个不打扰、不瞎编、只查不动的本地信息助手。

> **构建说明**：本项目从**零代码**起步（起点是空目录），仓库内全部代码、样式、脚本与文档均由
> **AI 编码助手**（DeepSeek 模型驱动）在真实需求驱动下生成，人类负责提需求、验收与决策。
> 详细说明见 [项目说明书.md](项目说明书.md#构建方式零代码起点ai-生成)。

## 2. 系统架构

### 2.1 组件

| 组件 | 文件 | 作用 |
|---|---|---|
| 悬浮窗主进程 | `src/main.js` | 窗口、点击穿透、拖动、缩放、后端托管、wiki 桥接 |
| 渲染层 | `src/index.html` + `src/style.css` | 磨砂面板、聊天、Markdown、截图、菜单与二级视图 |
| 本地服务 | `src/server.js` | HTTP 接口、安全红线拦截 |
| 配置与客户端 | `lib/config.js` | 路径、API Key、OpenAI 客户端、AlecaFrame 凭据 |
| MCP 管理 | `lib/mcp.js` | 连接两个 MCP、工具注册与裁剪、参数归一化、结果缓存 |
| Agent | `lib/agent.js` | Ordis 人设、上下文、工具循环、SSE 流式 |
| 遗物速查 | `lib/relic.js` | OCR、中英翻译、查表、排序、格式化 |
| 数据服务 A | `tools/wf-mcp-lite/server.mjs` | 自研 MCP（15 个工具） |
| 数据服务 B | `tools/warframe-inv.exe` | AlecaFrame MCP（11 个工具） |

### 2.2 启动流程

```
双击 start-overlay.vbs
   └─ electron.exe 启动（无控制台窗口）
        ├─ 读 userdata/bubble-size.json，按上次尺寸贴屏幕右下角
        ├─ 探测 3000 端口 → 空闲则拉起 src/server.js
        │     └─ server.js 再拉起 wf_market、wf_inv 两个 MCP 子进程
        ├─ 4 秒后预热 wiki 隐藏窗口（过 Cloudflare，约 5–7 秒）
        └─ 显示悬浮图标
```

启动约 10 秒后一切就绪；期间点开面板可以正常聊天，wiki 稍后可用。

### 2.3 一次问答的流程

```
输入文字 / 粘贴截图 → POST /api/chat（stream）
   ├─ 安全红线检查：命中 → 直接返回固定警报（不调模型）
   ├─ Agent：Ordis 提示词 + 最近 8 轮上下文 + 按意图裁剪后的工具列表
   ├─ 模型决定调用工具 → MCP 执行 → 结果回填 → 继续生成（最多 6 轮）
   └─ SSE 增量返回 → 前端边收边渲染 Markdown
```

### 2.4 关闭流程

`☰ → 退出`、`Ctrl+Shift+Q`、或关闭悬浮窗：

```
停止 src/server.js → taskkill /T 清掉两个 MCP 子进程 → 退出
```

## 3. 功能清单

### 3.1 对话与上下文

- 流式输出（打字机效果），失败自动回退非流式；
- 保留最近 **8 轮**对话；图片只保留最近 **2 轮**，更早的图替换为文字占位，避免请求过大；
- 菜单 →「API 凭据」→「清空上下文」可手动重置；
- 模型：`deepseek-chat`（纯文字）、`deepseek-flash`（带图时自动切换，支持视觉）。

### 3.2 装备与属性查询

战甲、武器、Mod、Prime 套装：基础属性、极性、被动与技能、掉落来源、杜卡德、制作材料、紫卡倾向。
数据来自离线 `warframe-items` 库（1.5 万条）+ market v2 的补充字段，**不联网也能查属性**。

### 3.3 市场价格与交易密语

- 输出：最低价、在线中位价、在线卖家数、收购单、前 3–5 个在线卖家；
- 只列 `status = ingame` 的卖家，按价格升序；
- 每个卖家给一条可复制密语：

```
/w {卖家名} Hi! I want to buy: "{物品}" for {价格} platinum. (warframe.market)
```

- Mod 类按最高等级过滤卖单（避免 R0 垃圾单把价格压到 2p）。

### 3.4 掉落与刷取

按物品名查遗物 / 地点 / 概率 / 稀有度；Prime 部件会合并四档精炼（完好/优良/无瑕/光辉），只显示最高概率并注明。
`farm_guide` 会综合掉落与当前市场价，给出「自己刷还是直接买」的判断。

### 3.5 实时世界状态

希图斯昼夜、福尔图娜温度、魔胎之境 FASS/VOME、虚空裂缝（按稀有度分组）、突击三阶段、虚空商人、入侵、限时警报。

- 双源并行：DE 官方 `worldState.php` + `tenno.tools`；
- 60 秒缓存 + 55 秒后台预热，缓存命中时 **1ms** 返回；
- 两源都不可达时用 6 小时内的快照，并在文首标注「⚠️ 快照时间」。

### 3.6 个人库存（依赖 AlecaFrame）

白金、信用点、Endo、Ducats、Aya、段位、遗物清单、已拥有战甲武器、紫卡、配卡、声望。
数据只在本机读取，来源是 AlecaFrame 的 `lastData.dat`。

> 前提：Overwolf + AlecaFrame 正在运行、且至少同步过一次；否则会明确回答「Ordis 无法读取本地库存」，不会编数字。

### 3.7 新手路线建议

`beginner_guide` 工具，五个主题：开局顺序、初始战甲对比、白金怎么花、氏族、Mod 优先级。
内容基于本地数据（战甲基础属性、Mod 等级曲线），不联网抓社区攻略。

### 3.8 今日推荐

`daily_picks` 工具：基于 market 实时价 + 本地掉落，给 1–3 条「今天补什么卡 / 刷还是买」。
世界状态不可用时会在文首标注，不影响推荐本身。

> 这两个工具**不再是「降级版」**：只要库存可读，Agent 会优先结合你的真实库存给建议（见 3.9）。

### 3.9 数据驱动的工作流（重要）

系统提示词里写死了三条硬规则：

1. 问「今天做什么 / 推荐 / 该练什么」→ **必须先调库存工具 + 世界状态**，再给建议；
2. 库存读不到 → 只回「Ordis 无法读取本地库存，请确认 AlecaFrame 已开启并同步。」，不猜；
3. 问配卡 → 先查库存与已有配卡，缺 Mod 要明说「您的库存中缺少 X Mod」并给替代方案。

### 3.10 截图识别（多模态）

- `Ctrl+V` 粘图 → 自动压缩到最长边 1568px / JPEG 0.92 → 缩略图预览（可点 × 取消）；
- 发送后图显示在气泡内，点图可放大；
- 适用于：面板自拍问答、装备界面、聊天截图、开核桃奖励界面。

### 3.11 开核桃秒选（遗物速查）

1. 点输入框右侧 🎁 进入**遗物模式**（按钮高亮、面板暖色边框、右下角圆点）；
2. 遗物模式下**面板不会自动收起**，方便你切回游戏截图；
3. `Ctrl+V` 粘贴奖励截图 → 自动识别，无需点发送；
4. 约 0.8 秒返回推荐，格式：

```
推荐选：{英文名}（{中文名}）（估值 xx p / xx 杜卡德）。其余：…
```

**排序规则**：
1. 出现 Forma 且其余奖励都 <10p → 选 Forma（硬通货）；
2. 否则按白金估值降序；
3. 白金相差 ≤2p 时，杜卡德高的优先。

再点一次 🎁 退出遗物模式，恢复正常「离开 1 秒收起」。

### 3.12 遗物奖励查询

问「Axi A1 出什么」或「哪个遗物出 Wisp Prime 系统蓝图」：

- 遗物 → 四档精炼概率表（铜/银/金 + 概率）；
- 部件 → 反查出现在哪些遗物（最多 25 条）。

数据来自 drop.wf.wiki 的公开数据，本地表 799 个遗物 / 4795 条奖励。

### 3.13 界面与交互

| 操作 | 行为 |
|---|---|
| 单击图标 | 展开面板（0.22s 缩放淡入） |
| 拖动图标 / 标题栏 | 移动窗口（4px 对齐，避免 DPI 半像素累积） |
| 鼠标离开面板 1 秒 | 自动收起（遗物模式除外） |
| 右下角把手 | 拉伸面板（最小 300×240） |
| 图标右下角把手 | 图标等比缩放 80–150px，记忆尺寸 |
| 图标在屏幕左半 / 右半 | 面板分别向右 / 向左展开，图标镜像 |
| `☰` | 二级菜单：遗物速查数据更新 / API 凭据 / 退出 |
| `Ctrl+Shift+Q` | 退出程序 |

### 3.14 安全关键词拦截

输入包含下列词时，**服务端直接返回固定警告，不调模型、不调工具**（约 2ms）：

```
淘宝 / 闲鱼 / 代充 / 代练 / 代肝 / 代打 / 代刷 / 共享账号 / 租号 / 卖号 / 买号 / 黑金 / 买白金 / 刷白金
```

返回内容为两段固定文案：风险提示（封号、黑金连带、账号安全）+ 请通过官方渠道。

## 4. 使用说明

### 4.1 运行环境

- Windows 10/11（64 位），国际服 PC 客户端；
- 无需安装 Node.js（使用项目内 Electron 自带的运行时）；
- 需要联网（market、DE 世界状态、wiki）；
- 查库存需要 Overwolf + AlecaFrame 已安装并同步过。

### 4.2 首次部署

1. 把整个 `overlay-demo` 文件夹放到任意目录（路径不要含 `&`、`%` 等特殊字符）；
2. 确认 `node_modules` 与 `tools` 目录完整（约 450 MB）；
3. 双击 `start-overlay.vbs`；
4. 点开面板 → `☰` →「API 凭据」→ 填 DeepSeek API Key → 保存；
5. 想查库存：填 AlecaFrame 的 `UserHash` 与 `PublicToken`（在 AlecaFrame 的 Stats 页面获取）→ 保存，服务会自动重连。

### 4.3 日常使用

- 双击桌面快捷方式（或 `start-overlay.vbs`）启动；
- 单击图标展开，问问题、粘截图；
- 鼠标移开自动收起；拖图标可换位置；
- 退出用 `☰ → 退出` 或 `Ctrl+Shift+Q`。

### 4.4 修改凭据（☰ → API 凭据）

| 项 | 说明 |
|---|---|
| DeepSeek API Key | 对话与识图都靠它；保存后立即生效，不用重启 |
| AlecaFrame UserHash | 库存服务的标识 |
| AlecaFrame PublicToken | 库存服务的鉴权（真正起作用的是它） |

三项都**明文回填**（本机自用工具，方便核对）；保存时只提交改动过的字段。
点「清空上下文」会清掉最近 8 轮对话记忆。

### 4.5 更新数据

面板 → `☰` →「遗物速查数据更新」：

| 按钮 | 作用 | 耗时 |
|---|---|---|
| 更新部件信息 | 重建 `all_relics.json`（612 条部件 + 中文名 + slug） | 约 30 秒 |
| 更新价格信息 | 重建 `relic_prices.json`（逐条查 market） | 约 6 分钟 |

也可以命令行（在 `overlay-demo` 目录）：

```bat
node scripts/update_relic_rewards.js   :: 遗物奖励库（drop.wf.wiki，约 10 秒）
node scripts/update_relic_parts.js     :: 部件表
node scripts/update_relic_prices.js    :: 价格表
node scripts/build_zh_map.js     :: 中英对照（灰机 wiki）
```

更新期间可以继续聊天，任务在后台跑；按钮会显示进度。

### 4.6 常见问题

| 现象 | 处理 |
|---|---|
| 双击没反应 | 看是否已有实例在跑（单实例）；`taskkill /IM electron.exe /F` 后再试 |
| 面板打开是空白/很小 | 通常是旧尺寸记忆异常：删 `userdata\bubble-size.json` 重启 |
| 提示「无法连接后端」 | 3000 端口被占：`netstat -ano | findstr :3000`，结束占用进程 |
| 库存读不到 | 确认 Overwolf + AlecaFrame 在跑、已同步；凭据是否过期 |
| wiki 查不到 | 首次启动需要 5–7 秒过 Cloudflare；失败会自动回退本地数据并标注 |
| 世界状态显示「快照」 | 上游接口临时不可达，等 1 分钟会自动重试 |
| 遗物推荐说「本地表里没有」 | 部件表缺该条目：先更新部件信息，再更新价格信息 |
| 中文名不对 | 在 `data\relic_zh.json` 的 `names` 里加一行，或重跑 `build_zh_map.js` |

### 4.7 数据、日志与备份

| 路径 | 内容 | 备份建议 |
|---|---|---|
| `config.json` | DeepSeek API Key | 不要外传 |
| `tools\config.json` | AlecaFrame 凭据 | 不要外传 |
| `data\all_relics.json` | 部件表（612 条） | 可重建 |
| `data\relic_prices.json` | 价格表（597 条有价） | 可重建，历史版本请自行备份 |
| `data\relic_rewards.json` | 遗物奖励库（1.2 MB） | 可重建 |
| `data\relic_zh.json` | 中英对照（655 条） | 建议备份（人工补过名） |
| `debug.log` / `server.log` | 运行日志 | 出问题再留 |

### 4.8 迁移到其它目录 / 电脑

- 整个文件夹拷走即可运行（内部路径都相对项目目录）；
- 需要一起带的：`config.json`、`tools\config.json`、`data\relic_zh.json`；
- 库存数据来自 AlecaFrame，换机后需要在新机同步一次。

### 4.9 升级与回滚

- 升级：覆盖代码文件（`src/`、`scripts/`、`tools\wf-mcp-lite`），保留 `config.json`、`userdata`、`tools\*.json`；
- 回滚：保留旧版文件夹即可；数据表向下兼容。

## 5. 数据来源与边界

**口径：全部为国际服 PC 数据。断源时只标注，不用国服数据、不估算冒充真实值。**

| 数据 | 来源 | 刷新方式 |
|---|---|---|
| 装备 / Mod / 掉落 / 杜卡德 | `warframe-items` 离线库（1.5 万条） | 随依赖升级 |

**明确不可用的上游**（已在工具层屏蔽，不会反复重试）：
Overframe、Reddit、`api.warframestat.us`、`raw.githubusercontent.com`（部分资源）。

**价格防钓鱼**：取最便宜 8 个在售单算中位数，剔除低于中位数 30% 的异常挂单，再取中位数。

## 6. 合规与法律声明

### 6.1 个人信息与数据处理

- 本工具**不收集、不上传**任何个人信息；
- 库存、紫卡、配卡等数据只在本机进程内读取与展示；
- 唯一外发的数据是**你主动发送的对话内容与截图**，发给你自己配置的模型服务商（默认 DeepSeek）；
- API Key 与 AlecaFrame 凭据以明文保存在本机 `config.json` / `tools\config.json`，请勿分享这两个文件或整个文件夹截图。

### 6.2 第三方服务条款

使用本工具即表示你同时受以下服务条款约束：

- **warframe.market**：仅做只读查询，遵守其 API 使用规范，不批量抓取、不转售数据；
- **Digital Extremes**：世界状态来自官方公开接口，遵守 Warframe EULA 与社区准则；
- **灰机 wiki**：仅按需读取词条正文用于回答，不镜像、不批量爬取；
- **DeepSeek**：对话内容受其服务条款与隐私政策约束。

### 6.3 游戏规则合规

- 本工具**不读取游戏内存、不注入进程、不修改游戏文件、不自动化游戏内操作**；
